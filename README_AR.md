# ROCK MAX – حجر ورقة مقص

هذه نسخة البداية للمشروع. تحتوي على:
- شاشة رئيسية عربية.
- لعب محلي لشخصين على هاتف واحد.
- حجر وورقة ومقص.
- إخفاء الاختيارات حتى يختار اللاعبان.
- عد تنازلي 3 ثوانٍ ثم إعلان النتيجة.
- نقاط وجولات وإعادة اللعب.

## تنبيه مهم
اللعب عبر الإنترنت، تسجيل الهاتف، الحسابات، الجمهور، المتجر والعملات ليست مفعلة في هذه النسخة بعد. سنضيفها في مراحل لاحقة مع خادم وقاعدة بيانات آمنة.

## متطلبات البناء
استخدم Node.js المتوافق مع Expo SDK 58، ثم:
1. npm install
2. npx expo-doctor
3. npx eas-cli build:configure
4. npx eas-cli build --platform android --profile preview

يجب استبدال REPLACE_WITH_EAS_PROJECT_ID بمعرف مشروع EAS بعد ربط المشروع بحسابك.
